# Citrine notes

## Caltech citrine = heated amethyst, GRR 3910, Rio Grande do Sul, Brazil
- Quartz index: http://minerals.gps.caltech.edu/FILES/Visible/quartz/Index.html (updated 18-Mar-2024). Stated: 2.29 mm thick; color due to small aggregates of iron oxide [primary: Caltech page text, paraphrased].
- Only images are linked (http://minerals.gps.caltech.edu/FILES/Visible/quartz/Citrine_3910_spectrum.jpg and Citrine_3910_large.jpg). NO digital data file is linked. Nothing saved.
- Amethyst data file on same index: http://minerals.gps.caltech.edu/FILES/Visible/quartz/ameth.bo (Anahi, Bolivia, not heated; not fetched).
- Ametrine page http://minerals.gps.caltech.edu/Ametrine/Index.html (not data): says citrine color is Fe3+ (aggregated/hydrated clusters), amethyst color from radiation-oxidised iron (Fe4+ model), both about 40 ppm iron (units not given there) [review: Caltech web page].

## Scientific Reports 2020, heated amethyst color (doi 10.1038/s41598-020-71786-1; text via Europe PMC PMC7483767)
- 20 natural South African amethysts, 7 mm diameter x 4 mm thick plates, heated 300-600 C. Population CIELAB means per temperature (Table 3, e.g. 20 C: L* 39.25, a* 30.59, b* -29.51; 500 C: L* 78.81, a* -2.93, b* 13.26) [primary: Table 3]. Illuminant not found in the text read; no Fe analysis, no per-sample digital spectra, spectra only as Fig. 3b. Attributes the 545 nm band to Fe3+-O2- charge transfer [primary: paper text]. Population means: NOT single-sample, so not usable under the same-sample rule.
